# FastAPI Question-Answer App with PostgreSQL

A question-answer web application built using **FastAPI** and **PostgreSQL** for storing and managing questions and answers. The backend provides a REST API for creating and managing questions, choices, and retrieving them from a PostgreSQL database.

## Features
- Create new questions with multiple choices.
- Each choice can be marked as correct or incorrect.
- Store questions and choices in a PostgreSQL database.
- API endpoints for managing questions and retrieving them.

## Technologies Used
- **Backend**: FastAPI
- **Database**: PostgreSQL
- **ORM**: SQLAlchemy
- **API Documentation**: OpenAPI (auto-generated by FastAPI)
- **Python Environment**: Python 3.9+
- **Database Connectivity**: psycopg2

## Prerequisites

### 1. Install PostgreSQL
Ensure you have PostgreSQL installed and running on your system. You can follow the [PostgreSQL installation guide](https://www.postgresql.org/download/) for your operating system.

### 2. Python Environment
Make sure you have Python 3.9+ installed. You can check your Python version with the following command:
```bash
python --version 3.9
```

### 3. Create a virtual environment and activate
```bash
python -m venv venv
source venv/bin/activate  # On Windows, use venv\Scripts\activate
```
### 4. Install the requirements
``` bash
pip install -r requirements.txt
```
